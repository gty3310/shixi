# 更新日志（弦歌 Mac 版）

本文件只记 Mac 版（macos/）的变更，与安卓版 CHANGELOG.md 分开维护。
格式遵循 Keep a Changelog，版本号遵循语义化版本。

## [0.2.0] - 2026-11-23

在纯阅读之上加听读：本地音频、播放器、遍数（与安卓同一本账）。

### 新增

- 本地加音频（书级绑定）：播放条「添加音频」经原生桥弹 NSOpenPanel
  选整本音频文件，绑定以安全书签存本机、重启自动恢复；壳经
  `xiange://audio/<bookId>` 流式供出（支持 Range，进度可拖）。
  未绑定的书播放键置灰、书卡与播放条标「未添加音频」，不假装能播。
  音频永不进 repo/.app、不复制不上传。
- 底部播放条（深色横贯，按已定原型）：播放/暂停、进度条拖动 seek、
  ±15 秒、倍速 0.75×/1×/1.25×/1.5×/2×、当前章标题与时间、循环三态
  （顺序播放 / 单章循环 / 整本循环）。
- 播放跟随：按逐句 startMs/endMs 高亮当前句并自动滚动（横竖排同）；
  点句跳播到该句；篇章行 ▶ 从该章章首播。
- 遍数（与安卓同一本账）：存储
  `~/Library/Application Support/弦歌/chapter_stats.json`，结构与安卓
  chapter_stats.json 逐字对齐（`bookId|章序|yyyy-MM-dd` → `{a, m}`），
  壳侧原子落盘。自动计数移植安卓 ChapterProgressTracker（armed 基线
  防误计、越章界计一遍、整本播完 flush 兜底；中途退出不计）。
- 书卡改版：今日大字 + 今日/本周/上周/本月/总计五档统计行（整本＝
  Σ各章 ÷ 章数、一位小数四舍五入，同安卓 BookCountFormat；日期边界
  周一起，同安卓 Store 口径）。
- 篇章行「今日 X 遍」chip：点开编辑弹层（− ＋ 步进 + 直接输数，点
  「存」才以差值走 adjustChapterToday 写回：增加入 m、减少先扣 m 再
  扣 a、下限 0；非法输入拦截不写），同安卓 v1.30 交互口径。
- Web 核心新增纯逻辑模块 stats.js（账/日期/折算/编辑校验）与
  playcore.js（计数判定/章界表/句定位），浏览器与 Node 双用；
  player.js 为浏览器侧播放控制。无壳浏览器预览自动回退（文件选择
  绑音频、localStorage 存账）。
- 本机验证：tools/dev_check.mjs 扩展至 80 项（新增遍数账写回语义、
  五档聚合、折算、编辑校验、tracker armed/越界/flush、章界表与句
  定位对账），全过；另以 jsdom 真加载组装预览做装配冒烟 18 项
  （书卡/篇章行/编辑弹层/无音频提示/点句），全过。

### 与安卓口径的差异

- 安卓多声音各有时间轴、按声音 scale 换算章界；Mac 每书只绑一个
  音频文件，直接用内容原始时间轴（无 scale 层）。
- 安卓的章级播放模式与循环范围细分未移植；Mac 循环只有三态。
- 计数账结构按简报的嵌套描述改为与安卓实际文件逐字一致的扁平键
  结构——两端同账以安卓现行格式为准。

### 未包含（后续版本路线）

- 跟读模式、点句笔记/标记、识读、两端同步。

### 已知未验

- Swift 壳未在 macOS 上实编译（开发机为 Linux VM）：桥消息、书签
  解析、xiange://audio 取流与 Range、WKWebView 内 <audio> 播放与
  跟随滚动的实际表现，待在用户的 Mac 上构建后验收。
- jsdom 冒烟中媒体方法为打桩：真实音频的时长读取、倍速与 seek
  行为未在本机验过。

## [0.1.0] - 2026-11-23

首个版本：纯阅读。

### 新增

- Mac 工程骨架：Swift 薄壳（窗口 + WKWebView + `xiange://` 本地资源
  服务）+ Web 阅读核心，`macos/build.sh` 一条命令构建出 `弦歌.app`；
  `--web-only` 可组装纯 Web 预览。
- 横版阅读界面（按已定 UI 原型）：左栏书目/篇章列表、右阅读页；
  三本书可选书选章——《大学》12 节、《中庸》24 小节、《论语》20 篇。
- 阅读能力：繁/简切换、拼音开关、古读标红开关（大学 60 / 中庸 138 /
  论语 237 字次，与安卓同一份标红清单）、注释开关与版本切换
  （《大学》直解/集注/耕夫、《中庸》直解/集注、《论语》lunyu.ai
  白话导读）、注块只在句组末尾显示一次、横排与竖排阅读（竖排注块
  不进列流，点句在左侧注栏显示所在注块）。
- 内容零副本：三本书正文/注释/标红清单均由 build.sh 在构建时从共用
  资产源（本 repo assets 与书库工作副本）拷入 .app，macos/ 内不存副本。
- 本机验证脚本 tools/dev_check.mjs：以真实内容源对账三本书的章句数、
  标红字次、注块落点与只显一次不变量、渲染冒烟（本版 31 项全过）。

### 未包含（后续版本路线）

- 音频播放与本地添加音频、底部播放条、遍数记录（口径与安卓
  chapter_stats 对齐）、点句笔记/标记、跟读、识读、两端同步。

### 已知未验

- Swift 壳未在 macOS 上实编译（开发机为 Linux VM）：构建与窗口呈现
  待在用户的 Mac 上首次构建验收；Web 核心已在本机以 Node 实跑验证
  并组装预览实测 HTTP 200。
